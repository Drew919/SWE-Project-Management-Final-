ARCHONPM
SWE 4663 Group 5 final project
ArchonPM is a Windows desktop app to track projects, teams, requirements, risks, and logged time

PREREQUISITES
- Windows 10 or 11
- Visual Studio 2022 with the .NET desktop and WinUI workloads
- .NET 8 SDK

HOW TO RUN THE APPLICATION
Execute run.bat in the current working directory
Alternate method to launch application:
1. Open ArchonPM.csproj in Visual Studio 2022
2. Set the platform to x64
3. Press F5
